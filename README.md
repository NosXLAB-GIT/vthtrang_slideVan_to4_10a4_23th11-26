# 🎀 Từ Bỏ Quan Niệm "Trọng Nam Khinh Nữ" — Cinematic HTML Presentation

Bài thuyết trình tương tác dạng điện ảnh (scroll-driven) môn Ngữ Văn, xây dựng hoàn toàn bằng **Vanilla HTML, CSS & JavaScript** trong một file duy nhất. Dự án kết hợp chiều sâu của bài nghị luận xã hội với phong cách **Hello Kitty Kawaii Editorial** — dùng nét mềm mại, ấm áp để tôn vinh bình đẳng giới và khẳng định giá trị con người không phụ thuộc vào giới tính.

---

## ✨ Tính năng nổi bật

- **Single-File & Offline-Ready:** Không cần cài đặt framework, không cần build step, mở trực tiếp trên trình duyệt (`file://`).
- **Thẩm mỹ Hello Kitty Kawaii Editorial:** Phối màu tương phản cao giữa nền tối dịu mắt (*Berry Plum*), hồng pastel và trắng kem, đảm bảo dễ đọc trên máy chiếu lớp học.
- **Chuyển động mượt mà (60fps):** Hiệu ứng parallax theo con trỏ chuột, chữ 3D tách ký tự, chuyển cảnh ruy băng đặc trưng và pháo hoa nơ đỏ ở slide kết.
- **Trình phát Video tích hợp (Slide 3):** Hỗ trợ nạp trực tiếp file video từ máy tính để trình chiếu minh họa ngay trong slide.
- **Chế độ chỉnh sửa trực tiếp (Editor Mode):** Nhấn phím `S` để sửa chữ, thay ảnh, nạp video và xuất lại file HTML mới mà không cần đụng vào code.
- **Hỗ trợ tiếng Việt chuẩn xác:** Tối ưu font bo tròn (`Quicksand`, `Nunito`, `Playfair Display`) và khoảng đệm dòng để không bị cắt mất dấu tiếng Việt.

## 🎮 Phím tắt điều khiển

| Phím / Thao tác | Chức năng |
| :--- | :--- |
| `Cuộn chuột` / `Vuốt` | Chuyển slide hoặc chuyển bước (step) trong slide |
| `←` `→` / `Space` / `PgUp` `PgDn` | Lùi / Tiến slide |
| `Home` / `End` | Nhảy nhanh về slide đầu / slide cuối |
| `G` | Mở lưới tổng quan tất cả các slide (Overview Grid) |
| `F` | Bật / Tắt chế độ toàn màn hình (Fullscreen) |
| `S` | Mở **Editor Mode** (chỉnh sửa nội dung & thay ảnh/video) |
| `Esc` | Đóng các cửa sổ pop-up / lightbox / Editor Mode |

---

## 🚀 Hướng dẫn sử dụng & Chỉnh sửa

1. **Chạy bài thuyết trình:** Tải file `index.html` về máy và mở bằng Chrome, Edge hoặc Safari. Nhấn `F` để phóng to toàn màn hình khi chiếu lên lớp.
2. **Thay ảnh, video hoặc sửa chữ:**
   - Nhấn phím **`S`** để mở bảng điều khiển **Editor Mode** bên cạnh phải.
   - Bấm trực tiếp vào chữ trên slide để sửa, hoặc chọn **Replace image / Upload video** tại các khung hình.
   - Bấm **Save HTML** để tải về file `.html` mới đã lưu toàn bộ thay đổi.
